# Notifications

## MVP
In-app notifications (`notifications` table: user_id, order_id, title, message, read_at) for:
- Order submitted / confirmed / rejected
- Modification requested
- Production milestone changes visible to the customer
- Ready for delivery / dispatched / delivered
- Quote revised

The customer tracking page also shows the latest admin message or modification request.

## Optional
Email first, then WhatsApp/SMS, and only once the integration is approved and configured.
Pick the notification method before deciding whether email is a required checkout field.
