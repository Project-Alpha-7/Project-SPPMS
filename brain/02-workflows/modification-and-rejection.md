# Modification and Rejection Flow

## Modification request
1. The admin selects **Request Modification**.
2. The admin enters a reason and instructions (**required**).
3. The order status changes to `Modification Requested`.
4. The customer sees the request on the tracking page or in their order view, plus a notification.
5. The customer uploads a corrected file or updates the details they're allowed to change.
6. The admin reviews the revised submission.
7. The admin confirms or requests another change.

Replacement artwork uploads are allowed only while a modification is requested.

## Customer-initiated change
A customer can ask for a change **before production begins**, and the admin must approve it.

## Rejection
- A reason is **required**.
- The order stays in the records. Never silently delete rejected orders.

## Quote changes
If the admin changes the quote during review, record the reason and show the revised amount to the
customer. See [../03-features/pricing.md](../03-features/pricing.md).
